# BACKTEST PROTOCOL

`SPECIFY → IMPLEMENT → FREEZE → TEST`

Suggested split from the master brief:
- 2005–2018 Development
- 2019–2022 Validation
- 2023–2025 Holdout
- 2026+ Live forward test

Metrics include Chủ 1, Chủ 1+2, Top3, Top5, Đài 1, Any Station, top Day Score subsets, best 4/7/10 days per month, N, hit rate, delta vs theoretical random baseline, confidence interval and rolling windows.

Changing a formula after observing holdout requires a new model version; do not overwrite V1.
