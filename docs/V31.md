# XSKT2 V3.1 — Station Results & Research UX

- Today shows Universal and, when configured, Personal results by exact station name. All-station summary requires all expected station rows; named station only uses that station. Missing/invalid rows remain unavailable. A WIN means a matching tail, not a profitable wager.
- User-selected station is localStorage only; absent on another weekday falls back to all stations without silently selecting a different station. Clicking a historical stats row transfers its scope to Today. Selecting a station does not change core picks.
- Station research shows the historical fraction of completed station draws where at least one of the displayed two numbers occurred, for 10/30/100 prior draws. This is a descriptive conditional historical statistic, not a calibrated next-draw probability. No automatic ranking or betting recommendation. Existing detailed research remains accessible. Station distribution q is approximate BH-FDR across the loaded stations, not a mechanical diagnosis.
- Stats supports first scheduled station, all stations, and named stations; dates without valid scoped data excluded from scored sample. The first station is now explicitly taken from the schedule, not input array order. All stations requires complete daily coverage. Historical comparison limited to the existing 2026+ calendar.
- The old Universal and Personal scoring engines, crawler, raw and derived data, report format, ledger and workflows are unchanged. Updated version labels, service worker cache and production check include new assets.
- New unit tests are run from `scripts/check_web.sh`; no new Python or JS dependencies. Test locally and verify Pages after push. Existing source-probe and historical-recovery limitations remain.
