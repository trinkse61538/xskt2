# XSKT2 V3.3 — Monthly Guide & Budget Review

Base: XSKT2 V3.2. Apply on a clean checkout. No prediction engine, historical records, workflows or Personal profile changes.

- Same monthly selection and station-1 scoring as V3.2; custom count 1–31 and custom start. No spillover.
- Amount and steps synchronize. Explicit maximum total hypothetical cost, initially zero. Fixed-amount scenario, chronological review, all repeated tails counted. No inferred losses for missing data. First WIN stops review even if net P/L is negative.
- Historical-only comparison of the legacy XSKT V4.5 progression formula, with same budget cap. No future escalation schedule, stake optimization or guaranteed profit. The comparison is retrospective, not proof of an advantage.
- UI labels and PWA cache upgraded; tests added.

## Install

```bash
cd ~/Desktop/xskt2
git status --short
git pull --ff-only origin main
python3 ~/Downloads/xskt2-v33-patch/apply_patch.py --check
python3 ~/Downloads/xskt2-v33-patch/apply_patch.py
source .venv/bin/activate
npm test
bash scripts/check_web.sh
git diff --stat
git status --short
```

After reviewing and passing tests, commit the affected files. The script verifies all anchors before writing; do not run if your checkout has unrelated local changes. No history workflow run required. The default budget is 0, and should be set explicitly for a hypothetical cost scenario.
