# XSKT2 V3.6 — All Days / Station Schedule

Requires V3.5.0. Adds daily scheduled station names, marks the first scheduled station (Đài 1), and displays observed WIN/MISS/pending/missing/unavailable per station for the currently displayed pair. No predictive station ranking, no engine, guide, or history changes. The calendar uses the existing configured weekly schedule, not live schedule verification. Search also matches station names without Vietnamese accents and the displayed mode's picks.
