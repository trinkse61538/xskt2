# XSKT2 V3.8.1 — Dò vé XSMN

Supports upgrades from unmodified V3.7.0 or V3.8.0. Default lookup mode is six-digit ticket; two-tail mode remains available. Match each prize's suffix, exact six-digit jackpot, and exactly one wrong digit (first: phụ đặc biệt; other positions: khuyến khích). Report all matching prize rows independently, not a payout guarantee. Ticket must match actual issuer, date and published rules. No near match is a win except the two explicitly defined jackpot-derived prize rules.

Six-digit lookup uses the existing accepted derived year index and reads original full prize values for the selected day. Validates lengths, counts, station/date and ordered tails against the derived index. For legacy records with a correction sidecar, checks raw SHA-256 and known source hosts and validates corrected values against the derived index. No guessed digits, no missing-as-MISS. Historic records do not independently establish completeness of scheduled stations; six-digit mode starts 2017-01-01 and uses common present-day prize structure, not an authoritative historical entitlement checker. No changes to crawler, predictions, backtest or data files.
