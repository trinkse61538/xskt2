# DATA SCHEMA V1

Universal yearly files: `data/universal/universal-YYYY.json`.

Each daily record includes calendar context, seasonal state, relations, gua, event-time gua, Universal day score/agreement/tier/month rank, top picks, full 00–99 ranking, and audit explanation.

Canonical history must preserve all 18 prize results per station and duplicate last-two-digit tails. Derived datasets may also expose `unique_hits`, but must never replace the canonical duplicate-preserving tails.
