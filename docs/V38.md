# V3.8 — Dò số XSMN

Sixth main tab (before Thêm). User-entered 00–99 only; accepts multiple numbers, deduplicates, preserves leading zero. Dates from 2005-10-01 through current Vietnam date. Reads validated year shard through existing loadHistoryIndex; refresh on explicit submission. No raw data or scoring engine changes. Counts each occurrence of a matching two-digit tail; station missing/invalid/duplicate never counts as MISS. Historical station lists follow stored records before 2026 and may be incomplete. Nearest = minimum absolute integer difference (no wraparound), all tied tails shown; signed delta is result minus input. Wrong positions = Hamming distance. Expand one-position matches and all 18 tails. Near matches do not count as hits or imply future odds. No financial calculations. All input stays in browser; no persistence of user-entered numbers.
